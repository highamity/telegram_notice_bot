# 텔레그램 공지 봇 (QNAP TS-251, Docker)

채팅방(또는 1:1)별로 짧은 공지를 **키워드 형태로 저장/조회**하는 봇입니다.  
데이터는 **SQLite 파일 1개**로 저장됩니다.

## 현재 동작

- 명령어는 `/` 대신 `!` 접두사를 사용합니다.
- 그룹에서도 **관리자 제한 없이 누구나 저장/삭제**할 수 있습니다.
- 키워드 조회는 `!키워드`처럼 입력하면 됩니다.

## 명령어

### 1. 공지 메모
| 입력 | 설명 |
|------|------|
| `!기억 키 내용...` | 공지 저장 |
| (메시지에 답장 후) `!기억 키` | 답장한 메시지 본문 저장 |
| `!키` | 저장된 공지 (또는 디데이) 조회 |
| `!목록` | 현재 채팅의 키 목록 조회 |
| `!삭제 키` | 저장된 공지 삭제 |

### 2. 일정 등록 및 자동 알림
| 입력 | 설명 |
|------|------|
| `!일정 날짜/시간 내용` (또는 `!일정 내용 날짜/시간`) | 일정 등록 및 해당 일시 도래 시 자동 알림 (KST, 순서 무관) |
| `!일정목록` (또는 `!일정`) | 예정된 일정 목록 및 ID 조회 |
| `!일정삭제 ID` | 지정 ID 일정 삭제 |

- **순서 무관**: `!일정 9/20 14:00 회의`와 `!일정 회의 9/20 14:00` 둘 다 정상 인식됩니다.
- 날짜 입력 지원: `9/20`, `9월20일`, `9.20`, `2026-09-20`, `오늘`, `내일`, `모레` 등 (연도 생략 시 올해/내년 자동 적용)
- 시간 입력 지원: `14:00`, `14시`, `오후 2시 30분` 등 (시간 생략 시 오전 09:00 기본 적용)
- **모호성 방지 팁**: "내일 치과"처럼 날짜 단어가 포함된 일정명은 `"내일 치과"`처럼 따옴표로 감싸거나 `내일치과`로 붙여 쓰면 가장 안전하게 인식됩니다.

### 3. 디데이 & 기념일 (경과일 및 매년 반복 알림)
| 입력 | 설명 |
|------|------|
| `!디데이 이름 날짜` (또는 `!디데이 날짜 이름`) | 디데이 또는 기념일 등록 (순서 무관, 과거일/키워드 자동 판별) |
| `!기념일 이름 날짜` (또는 `!기념일 날짜 이름`) | 매년 반복 알림 기념일로 등록 (매년 당일 오전 09:00 KST 알림) |
| `!디데이` (또는 `!기념일`) | 등록된 디데이/기념일 전체 목록 조회 |
| `!디데이 이름` (또는 `!이름`) | 특정 디데이/기념일 일수 즉시 계산 조회 |
| `!디데이삭제 이름` (또는 `!기념일삭제 이름`) | 등록된 디데이/기념일 삭제 |

- **순서 무관**: `!디데이 수능 11/19`와 `!디데이 11/19 수능` 둘 다 동일하게 처리됩니다.
- **[매년 반복 기념일 🔔]**:
  - 과거 날짜(예: `2020-05-10`), `생일`/`생신`/`결혼`/`기념일`/`주년` 키워드가 포함된 경우, 또는 `!기념일`로 등록된 경우
  - **시작 당일을 1일로 계산** (예: `2321일째`)
  - 매년 해당 월/일 오전 09:00(KST)에 **N주년 축하 알림 자동 발송** (예: `🎉 [기념일 알림] 오늘은 '결혼' 4주년입니다! (1462일째)`)
- **[1회성 목표 🎯]**:
  - 키워드가 없는 미래 날짜(예: `수능 2026-11-19`)
  - 목표일까지 잔여 일수 카운트다운 (`D-64`, `D-Day`)
  - 당일 아침 09:00에 **`⏰ [디데이 알림] 오늘은 '수능' D-Day입니다!`** 1회 발송 후 완료

### 4. 도움말
| 입력 | 설명 |
|------|------|
| `!도움말` (또는 `!도움`, `/help`) | 사용 가능한 전체 명령어 도움말 안내 |

예시:

- `!기억 회식 이번 주 금요일 7시`
- `!일정 9/20 14:00 팀 회의` (또는 `!일정 팀 회의 9/20 14:00`)
- `!일정 내일 10:00 치과` (또는 `!일정 치과 내일 10:00`)
- `!일정`
- `!일정삭제 1`
- `!디데이 수능 2026-11-19` (또는 `!디데이 2026-11-19 수능`)
- `!디데이 결혼 2020-05-10` (또는 `!디데이 2020-05-10 결혼`)
- `!기념일 철수생일 10/25`
- `!결혼`
- `!디데이삭제 수능`

## BotFather 설정 (중요)

그룹에서 `!기억`, `!목록`, `!키워드` 같은 일반 텍스트를 받으려면  
**Privacy Mode를 꺼야** 합니다.

1. [@BotFather](https://t.me/BotFather) 열기
2. `/setprivacy`
3. 봇 선택
4. `Disable`

## 봇 생성

1. [@BotFather](https://t.me/BotFather)에서 `/newbot`으로 봇 생성
2. 발급된 토큰 복사
3. 봇을 사용할 그룹에 초대

## QNAP에서 실행 (Docker)

```bash
cd telegram_notice_bot
docker build -t telegram-notice-bot .
docker run -d --name telegram-notice-bot \
  --restart unless-stopped \
  -e TELEGRAM_BOT_TOKEN="YOUR_TOKEN_HERE" \
  -v /share/Container/telegram_bot_data:/data \
  telegram-notice-bot
```

- 컨테이너 내부 DB 기본 경로: `/data/notices.db`
- 필요 시 환경변수 `NOTICE_DB_PATH`로 경로를 직접 지정할 수 있습니다.

컨테이너를 수정 코드로 다시 올릴 때:

```bash
docker build -t telegram-notice-bot .
docker stop telegram-notice-bot
docker rm telegram-notice-bot
docker run -d --name telegram-notice-bot \
  --restart unless-stopped \
  -e TELEGRAM_BOT_TOKEN="YOUR_TOKEN_HERE" \
  -v /share/Container/telegram_bot_data:/data \
  telegram-notice-bot
```

## 로컬 테스트 (Windows)

```bash
cd telegram_notice_bot
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
REM .env 파일에 TELEGRAM_BOT_TOKEN 입력
python bot.py
```

기본 DB 경로는 `bot.py` 옆의 `notices.db` 입니다.

## 보안 주의사항

- `.env` 파일과 토큰은 절대 커밋하지 마세요.
- 저장된 텍스트는 입력한 그대로 전송됩니다.

## 파일 구성

- `bot.py` : 봇 로직
- `storage.py` : SQLite 저장 로직 (공지, 일정, 디데이)
- `date_parser.py` : 날짜/시간 파싱 및 디데이 계산 유틸리티
- `requirements.txt` : 의존성 목록
- `Dockerfile` : 컨테이너 빌드 설정
- `.env.example` : 환경변수 예시
